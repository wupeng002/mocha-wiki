# 用例统计看板

> 本页由 Dataview 自动生成，无需手动维护。修改用例的属性（状态/优先级等）后自动刷新。

## 用例总览

```dataview
TABLE WITHOUT ID
  file.link AS "用例",
  所属模块 AS "模块",
  优先级 AS "优先级",
  状态 AS "状态",
  执行人 AS "执行人"
FROM "用例库"
SORT 优先级 ASC, 用例编号 ASC
```

## 按状态统计

```dataview
TABLE WITHOUT ID
  状态 AS "状态",
  length(rows) AS "用例数"
FROM "用例库"
GROUP BY 状态
```

## 按模块统计

```dataview
TABLE WITHOUT ID
  所属模块 AS "模块",
  length(rows) AS "用例数"
FROM "用例库"
GROUP BY 所属模块
```

## 失败 / 阻塞用例（重点关注）

```dataview
LIST
FROM "用例库"
WHERE 状态 = "失败" OR 状态 = "阻塞"
```

## P0 用例清单

```dataview
LIST
FROM "用例库"
WHERE 优先级 = "P0"
```
